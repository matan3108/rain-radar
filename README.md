# מכ״ם הגשם שלנו

אפליקציה לטלפון שמראה גשם בזמן אמת בלהבים, באר שבע, נבטים והרצליה, עם הסברים פשוטים לילדים.

- **עכשיו**: לכל מקום, יורד גשם או לא, בשפה פשוטה, ומה הסיכוי לגשם ב-12 השעות הבאות.
- **מכ״ם**: מפה חיה עם סרטון של השעתיים האחרונות, ואז כמה שעות קדימה לפי התחזית. ליד כל מקום יש סמליל מזג אוויר שמשתנה עם הסרטון.
- **מילון**: כל מושג מוסבר ברמה של ילד בן 10.

הכתובת של האפליקציה: https://matan3108.github.io/rain-radar/

## הפעלת האתר (פעם אחת)

1. במאגר הזה ב-GitHub: **Settings** ← **Pages**.
2. תחת **Branch** בוחרים `main` ו-`/ (root)`, ולוחצים **Save**.
3. אחרי דקה או שתיים האפליקציה עולה בכתובת שלמעלה.

## התקנה בטלפון אנדרואיד

1. פותחים את הכתובת ב-Chrome.
2. לוחצים על הכפתור **התקנה** למעלה, או על שלוש הנקודות ← **התקנת אפליקציה** / **הוספה למסך הבית**.
3. האייקון מופיע במסך הבית ונפתח כמו אפליקציה רגילה.

## מאיפה הנתונים

- מכ״ם: [Rain Viewer](https://www.rainviewer.com) (תמונות מהעבר ועד עכשיו).
- תחזית וסמלילים: [Open-Meteo](https://open-meteo.com).
- מפה: Esri ו-OpenStreetMap.

התחזית היא ניחוש ויכולה לטעות. לאזהרות רשמיות בודקים תמיד גם את [השירות המטאורולוגי](https://ims.gov.il/he).

## קבצים

| קובץ | מה הוא עושה |
|---|---|
| `index.html` | כל האפליקציה: מסכים, מפה, נתונים |
| `manifest.webmanifest` | שם, אייקון וצבעים כשמתקינים בטלפון |
| `sw.js` | שומר את האפליקציה בטלפון כדי שתיפתח מהר. נתוני מזג האוויר תמיד נטענים מחדש |
| `icons/` | האייקונים |

כשמשנים את `index.html` כדאי להעלות גם את המספר ב-`CACHE` שבתוך `sw.js` (למשל `rain-radar-v2`), כדי שהטלפונים יקבלו את הגרסה החדשה.
